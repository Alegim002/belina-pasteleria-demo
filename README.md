# Belina · propuesta web

Demo comercial creada por Agallart Digital el 5 de octubre de 2026, a petición de Alex Gallart. No es la web oficial del negocio.

Catálogo ilustrativo, filtros, selección de una idea y formulario que prepara un resumen de consulta. No recoge ni almacena datos, no admite pedidos reales y no confirma disponibilidad o presupuesto. Los ejemplos y las ilustraciones SVG son propuestas, no productos ni fotografías reales de Belina. La continuación hacia WhatsApp queda pendiente de confirmar el número oficial; por ahora se puede copiar el mensaje. No se inventan precios, testimonios ni resultados.

Sitio estático autocontenido en `index.html`. GitHub Pages: desplegar desde `main`, carpeta raíz. No requiere dependencias ni credenciales. El perfil de referencia es `@belina.pasteleria`.
