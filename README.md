# Belina · propuesta web

Demo comercial creada por Agallart Digital el 5 de octubre de 2026, a petición de Alex Gallart. No es la web oficial del negocio.

Catálogo visual con fotografías del perfil @belina.pasteleria, filtros, selección de una idea y formulario que prepara un resumen de consulta. No recoge ni almacena datos, no admite pedidos reales y no confirma disponibilidad o presupuesto. La demo permite copiar el resumen; no envía mensajes a WhatsApp. No se inventan precios, testimonios ni resultados.

Fotos: tarta personalizada (reel Dbi4bLbMXsS), lemon pie (reel DYugDnJsPH0) y alfajores de maicena (publicación DYmnpKrjBzr). Cada ficha enlaza la publicación original.

Sitio estático en `index.html`, con tres fotografías JPG locales. GitHub Pages: desplegar desde `main`, carpeta raíz. No requiere dependencias ni credenciales.
